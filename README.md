# SmartGrid Energy — Customer Portal (Live Demo)

A single-file, self-contained interactive demo of the SmartGrid Energy customer portal.

**Live site:** https://nammi2011.github.io/Smart-Grid-Portal/

## What this is

`index.html` is a standalone HTML file — all CSS and JavaScript are inlined. It has
no build step, no dependencies, and makes no network calls. Open it directly in any
modern browser, or serve it from any static host.

The demo covers the preference center, program eligibility checks, the rate analyzer,
and a live "what if" rate simulator. All data is fictional.

## Running locally

Just open `index.html` in a browser. No server required.

## Deploying

Any static host works: GitHub Pages, Netlify, Vercel, Cloudflare Pages, S3 + CloudFront,
or plain shared hosting via FTP. Upload `index.html` and you're done.
